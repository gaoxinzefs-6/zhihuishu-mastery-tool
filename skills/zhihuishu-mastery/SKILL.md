# 智慧树 / 知到 掌握度自动答题

你正在通过一个**本地 PowerShell CLI** 操作真实浏览器。它不是 API，而是模拟鼠标，
所以每一步都要确认页面状态，失败要重试，不要假设成功。

## 何时使用

- 用户要求「把智慧树/知到课程的知识点掌握度刷满 / 刷绿」；
- 用户给了本仓库路径，要求用 `run.ps1` 推进；
- 需要批量完成 5 题一组的知识点测验。

## 前置检查（必须全部满足）

1. 系统是 Windows，有 PowerShell 5.1+；
2. Edge 已打开并登录智慧树，停在课程「掌握度」页；
3. 用户同意在运行期间不碰鼠标、不切标签页。

先跑：

```
powershell -ExecutionPolicy Bypass -File .\run.ps1 -Action status -Json
```

`state` 必须是 `mastery`，否则先让用户切到掌握度页（或用 `-Action back`）。

## 主循环

```text
1. run.ps1 -Action next -Json
   → {"ok":true,"point":"...","questions":[{index,type,stem,options}]}
2. 逐题作答，拼出答案串：
   - 单选: "B"
   - 判断: "T" / "F"
   - 多选: "ACE"
   - 5 题: "B|T|ACE|D|A"
3. run.ps1 -Action submit -Answers "<答案串>" -Json
   → {"ok":true,"score":100,"correct":5,"total":5}
4. run.ps1 -Action back -Json
5. 重复，直到 next 返回退出码 3（NO_MISSING_POINT）
```

## 答题规则

- 题目每次进入都会**重新随机**，绝不能复用上一次的答案字母；
- 按题干语义选最贴切的一项，优先教材原话；
- 判断题含「完全 / 唯一 / 所有」等绝对化表述，通常为「错」；
- 多选题只勾能明确对应的选项；
- `score < 80` 该点会回到灰色/黄色，需要重新 `next` 读题重做。

## 退出码处理

| 码 | 含义 | 动作 |
|---|---|---|
| 0 | 成功 | 继续 |
| 2 | 不在掌握度页 | 先 `back` |
| 3 | 没有灰色知识点 | 滚动页面再试；若到底则可能已完成 |
| 4 | 打开失败 | 重试一次，仍失败跳过并记录 |
| 5 | 提交失败 | 重新 `next` |

## 完成判定

页面顶部：**遗漏点 0、薄弱点 0、平均掌握度 ≥ 98%**。
满足后向用户汇报：完成了多少个知识点、平均掌握度、剩下的 80 分点位（如有）。

## 禁止

- 不要并行开多个实例（鼠标是全局资源）；
- 不要在用户操作鼠标时运行；
- 不要伪造 `score` 或跳过 `back`，否则颜色状态会失真。
